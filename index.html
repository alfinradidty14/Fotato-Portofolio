3 langkah mudah meng-online-kan Fotato

  1. 1. Buat Repository Baru di GitHub Beri nama misalnya fotato-portfolio atau username.github.io.
  2. 2. Upload File index.html Ini Simpan kode ini sebagai index.html lalu upload langsung ke branch main. Tidak perlu instalasi Node.js atau build tambahan.
  3. 3. Aktifkan GitHub Pages Buka menu Settings → Pages di repo GitHub Anda, pilih branch main / root lalu klik Save. Website Fotato Anda langsung aktif!
